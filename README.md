# Ajournal
Ce projet est un site web immersif qui transforme la lecture d’un roman en une expérience théâtrale et intime. À l’ouverture de la page, deux rideaux de velours rouge s’écartent lentement, révélant une scène qui prend la forme d’un carnet à doubles lignes, semblable à un cahier d’écolier.
# Carnet de scène – « Ce que je ne t’ai pas dit »

Bienvenue dans le site web qui transforme votre roman en une expérience de lecture théâtrale.  
À l’ouverture des rideaux, un carnet à doubles lignes se dévoile, contenant l’intégralité du récit.

## ✨ Aperçu

- **Animation d’ouverture** : deux rideaux rouges s’écartent avec fluidité.
- **Carnet numérique** : fond de cahier ligné, police manuscrite, ambiance chaleureuse.
- **Navigation par pages** : boutons Précédent / Suivant avec indicateur de progression.
- **Contenu complet** : synopsis, chapitres 1 à 20, épilogue, note de l’autrice.
- **Rejouer l’ouverture** : un bouton « Rouvrir le rideau » permet de rejouer l’effet théâtral.

## 🚀 Installation et utilisation

1. Téléchargez le fichier `index.html`.
2. Ouvrez-le dans n’importe quel navigateur moderne (Chrome, Firefox, Edge, Safari).
3. Laissez les rideaux s’ouvrir, puis naviguez dans l’histoire.
4. Cliquez sur **« Rouvrir le rideau »** pour revoir l’animation.

> Aucun serveur ni dépendance externe (hors Google Fonts et FontAwesome) n’est requis. Tout est inclus dans le HTML.

## 🎨 Personnalisation

- **Modifier le texte** : le roman est stocké dans la variable `FULL_STORY` en JavaScript. Vous pouvez y substituer votre propre contenu (respectez les balises HTML `<h2>`, `<p>`, etc.).
- **Changer les couleurs des rideaux** : modifiez les dégradés dans `.curtain`.
- **Ajuster le nombre de pages** : le découpage se fait automatiquement sur les titres (`<h2>`, `<h3>`). Vous pouvez adapter la logique dans la fonction de découpage.

## 👩‍🎨 Esthétique & inspiration

L’interface s’inspire de l’univers graphique de **Julien Neel** (auteur de la bande dessinée *Lou !*) :  
- Douceur des lignes, teintes crème et vieux rose,  
- Typographie arrondie et lisible (Gaegu, Fredoka One),  
- Éléments de carnet (lignes, coin de page, effet aquarelle).
